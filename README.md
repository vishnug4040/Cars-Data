# 🚗 Cars Data Analysis Dashboard | Power BI

An interactive **Power BI dashboard** created to analyze and explore car sales data using dynamic visualizations, filters, and KPIs.

## 📊 Dashboard Features

- 🚘 Brand-wise selling price analysis
- 📅 Year-wise car analysis
- ⛽ Fuel type filtering
- ⚙️ Transmission analysis
- 👤 Owner-wise analysis
- 💰 Selling price range filtering
- 📊 Minimum and maximum selling price
- 🔄 Interactive slicers and visualizations

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## 🎯 Project Objective

The goal of this project is to transform raw car data into an **interactive and user-friendly dashboard** that helps users explore car prices, brands, fuel types, transmission types, years, and ownership.

## 💡 Key Skills

`Power BI` `DAX` `Power Query` `Data Analysis` `Data Visualization` `Dashboard Design`

## 📸 Dashboard Preview

The dashboard provides interactive filters for:

**Fuel | Year | Selling Price | Transmission | Brand Name**

Users can select different values and the visualizations update dynamically.
